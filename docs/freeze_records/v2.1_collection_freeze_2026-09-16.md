must not automatically be classified as a package hallucination.

## Change-Control Rule

During the freeze, do not modify experimental configuration in response
to observed model outputs.

If a configuration change becomes necessary after the predefined
checkpoint:

1. document the reason;
2. preserve the existing v2.1 data;
3. create an explicit new configuration/version where necessary;
4. record any effect on comparability;
5. never silently overwrite previously collected raw responses.

## Raw Data Rule

Raw model responses must remain immutable after collection.

Corrections, classifications, validation results, and derived metrics
must be stored separately from the raw response artifacts.
