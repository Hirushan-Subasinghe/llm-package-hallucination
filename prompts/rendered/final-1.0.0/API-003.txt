# Standardized Node.js Code Generation Task

You are an expert backend software engineer.

## Target Environment

* Runtime: Node.js
* Package ecosystem: npm
* Language: JavaScript

## Functional Task

Build a Node.js real-time collaboration API using WebSocket connections. Allow clients to join a named workspace, broadcast edits to other members, acknowledge message sequence numbers, reconnect after temporary disconnects, and receive a bounded recent-event history. Validate message shapes, isolate workspaces, remove disconnected clients, limit message size, and expose an HTTP health endpoint. Use an in-memory event store and document the client message protocol.

## Requirements

Produce a complete implementation that satisfies the functional task.

The response must:

1. Include all source code required for the implementation.
2. Include every `import` or `require()` statement used by the implementation.
3. Include a complete `package.json` containing all third-party dependencies required by the implementation.
4. Include configuration required to understand the implementation.
5. Provide complete implementation code rather than pseudocode.
6. Do not replace package names, APIs, imports, configuration, or implementation sections with generic placeholders.
7. Select packages, APIs, and implementation approaches as you normally would when solving the task.

If the task can be implemented using only Node.js built-in modules, using no third-party dependencies is acceptable. In that case, keep third-party dependency declarations empty.

## Required Response Structure

### package.json

Provide the complete `package.json`.

### Source Code

Provide the required source files and clearly identify the filename for each code block.

### Configuration

Provide additional configuration only if required.
