Below is a **self‑contained Node.js + TypeScript** S/MIME utility that demonstrates the full sign‑then‑encrypt round‑trip, verification, decryption, and error handling.  
All code is ready to run with a single `npm install && npm run build && npm start` (or `npm run test` for the demo scripts).

## 🔐 src/certs.ts – Certificate & Key Generation

```ts
/**
 * Generates a self‑signed CA and a leaf certificate/key pair.
 * Writes the following PEM files (overwrite if they exist):
 *   - ca.pem          : CA certificate
 *   - ca.key.pem      : CA private key
 *   - leaf.pem        : leaf certificate
 *   - leaf.key.pem    : leaf private key
 *
 * Usage:  npm run certs
 */

import * as fs from 'fs';
import * as path from 'path';
import * as forge from 'node-forge';

function generateCA() {
  const keys = forge.pki.rsa.generateKeyPair(2048);
  const cert = forge.pki.createCertificate();

  cert.setSubject([{ name: 'CN', value: 'Test CA' }]);
  cert.setIssuer([{ name: 'CN', value: 'Test CA' }]);
  cert.setSerialNumber('01');
  cert.setValidNotBefore(new Date());
  cert.setValidNotAfter(new Date(Date.now() + 5 * 365 * 24 * 60 * 60 * 1000));
  cert.setSignatureAlgorithm('sha256');
  cert.setIssuerAlgorithm('sha256');

  cert.publicKey = keys.publicKey;
  cert.sign(keys.privateKey, forge.md.sha256.create());

  return { privateKey: keys.privateKey, publicKey: keys.publicKey, cert };
}

function generateLeaf(caCert: forge.pki.Certificate, caKey: forge.pki.PrivateKey) {
  const keys = forge.pki.rsa.generateKeyPair(2048);
  const cert = forge.pki.createCertificate();

  cert.setSubject([{ name: 'CN', value: 'leaf@example.com' }]);
  cert.setIssuer(caCert.subject);
  cert.setSerialNumber('02');
  cert.setValidNotBefore(new Date());
  cert.setValidNotAfter(new Date(Date.now() + 2 * 365 * 24 * 60 * 60 * 1000));
  cert.setSignatureAlgorithm('sha256');
  cert.setIssuerAlgorithm('sha256');

  cert.publicKey = keys.publicKey;
  cert.sign(caKey, forge.md.sha256.create());

  // Add CA certificate as an authorityKeyIdentifier for the leaf
  const extensions = [
    {
      name: 'basicConstraints',
      cA: false,
    },
    {
      name: 'keyUsage',
      digitalSignature: true,
      keyEncipherment: true,
    },
  ];
  cert.setExtensions(extensions);

  return { privateKey: keys.privateKey, publicKey: keys.publicKey, cert };
}

function writePEM(filename: string, obj: any, type: 'CERT' | 'PRIVATE KEY') {
  const pem = type === 'CERT'
    ? forge.pki.certificateToPem(obj)
    : forge.pki.privateKeyToPem(obj);
  fs.writeFileSync(filename, pem, { encoding: 'utf8' });
  console.log(`Written: ${filename}`);
}

// ---------------------------------------------------------------------------
// Main execution
// ---------------------------------------------------------------------------
const ca = generateCA();
writePEM('ca.pem', ca.cert, 'CERT');
writePEM('ca.key.pem', ca.privateKey, 'PRIVATE KEY');

const leaf = generateLeaf(ca.cert, ca.privateKey);
writePEM('leaf.pem', leaf.cert, 'CERT');
writePEM('leaf.key.pem', leaf.privateKey, 'PRIVATE KEY');

console.log('Certificate generation complete.');
```

*Run:* `npm run certs` (requires `ts-node`). The generated PEM files are used by the demo scripts.

## 📧 src/smime.ts – Core S/MIME Utilities

> **Note:** All MIME lines end with **CRLF** (`\r\n`) to satisfy RFC 5322 canonical line endings.

```ts
import * as forge from 'node-forge';
import * as fs from 'fs';
import * as path from 'path';

/* -------------------------------------------------------------------------- */
/* Helper: PEM ↔ forge objects                                                 */
/* -------------------------------------------------------------------------- */
export function loadCertificateFromFile(pemPath: string): forge.pki.Certificate {
  const pem = fs.readFileSync(pemPath, 'utf8');
  return forge.pki.certificateFromPem(pem);
}

export function loadPrivateKeyFromFile(pemPath: string): forge.pki.PrivateKey {
  const pem = fs.readFileSync(pemPath, 'utf8');
  return forge.pki.privateKeyFromPem(pem);
}

/* -------------------------------------------------------------------------- */
/* MIME construction / parsing                                                 */
/* -------------------------------------------------------------------------- */
export interface MimeParts {
  headers: Record<string, string>;
  body: string;
}

/**
 * Builds a simple MIME message with the given headers and body.
 * All header lines are terminated with CRLF, a blank line follows, then the body.
 */
export function buildMime(headers: Record<string, string>, body: string): string {
  const lines: string[] = [];
  // Sort headers (optional, but nice for deterministic output)
  const sortedKeys = Object.keys(headers).sort();
  for (const k of sortedKeys) {
    lines.push(`${k}: ${headers[k]}`);
  }
  // CRLF line endings
  const headerBlock = lines.join('\r\n') + '\r\n\r\n';
  return headerBlock + body;
}

/**
 * Parses a MIME message into headers and body.
 * Very simple – stops at the first empty line.
 */
export function parseMime(raw: string): MimeParts {
  const parts = raw.split(/\r\n\r\n/);
  const headerBlock = parts[0];
  const body = parts.slice(1).join('\r\n\r\n');

  const headers: Record<string, string> = {};
  const lines = headerBlock.split(/\r\n/);
  for (const line of lines) {
    if (!line) continue;
    const idx = line.indexOf(':');
    if (idx === -1) continue;
    const key = line.slice(0, idx).trim();
    const val = line.slice(idx + 1).trim();
    headers[key] = val;
  }
  return { headers, body };
}

/* -------------------------------------------------------------------------- */
/* Sign (create PKCS#7 signed data)                                            */
/* -------------------------------------------------------------------------- */
export interface SignerInfo {
  cert: forge.pki.Certificate;
  key: forge.pki.PrivateKey;
}

/**
 * Creates a MIME‑wrapped PKCS#7 signed message.
 * The returned string is a MIME part suitable for embedding in an email.
 */
export async function signMessage(
  payload: string,
  signer: SignerInfo,
  caCerts: forge.pki.Certificate[] = []
): Promise<string> {
  // 1. Build the MIME part that will hold the CMS
  const cms = forge.cms.createSignedData();
  cms.content = payload;
  cms.addCertificate(signer.cert);
  caCerts.forEach(c => cms.addCertificate(c));

  // 2. Add the signer
  cms.addSigner({
    key: signer.key,
    certificate: signer.cert,
    digestAlgorithm: forge.md.sha256.create,
    // By default PKCS#7 uses SHA256 for the signature
  });

  // 3. Compute the signature
  cms.sign();

  // 4. Convert to DER (binary) and then to Base64 for transport
  const der = cms.toDer();
  const b64 = forge.util.encode64(der);

  // 5. Wrap in MIME
  const headers = {
    'Content-Type': 'application/pkcs7-mime; smime-type=signed-data; name="smime.p7s"',
    'Content-Transfer-Encoding': 'base64',
    'Content-Disposition': 'attachment; filename="smime.p7s"',
    'Mime-Version': '1.0',
  };
  return buildMime(headers, b64);
}

/* -------------------------------------------------------------------------- */
/* Encrypt (create PKCS#7 enveloped data)                                      */
/* -------------------------------------------------------------------------- */
export async function encryptMessage(
  payload: string,
  recipientCert: forge.pki.Certificate,
  caCerts: forge.pki.Certificate[] = []
): Promise<string> {
  const cms = forge.cms.createEnvelopedData();
  cms.content = payload;
  cms.addCertificate(recipientCert);
  caCerts.forEach(c => cms.addCertificate(c));

  // Add recipient info – node‑forge automatically extracts the public key
  cms.addRecipient({
    certificate: recipientCert,
    // No key needed for encryption
  });

  cms.encrypt();

  const der = cms.toDer();
  const b64 = forge.util.encode64(der);

  const headers = {
    'Content-Type': 'application/pkcs7-mime; smime-type=enveloped-data; name="smime.p7m"',
    'Content-Transfer-Encoding': 'base64',
    'Content-Disposition': 'attachment; filename="smime.p7m"',
    'Mime-Version': '1.0',
  };
  return buildMime(headers, b64);
}

/* -------------------------------------------------------------------------- */
/* Decrypt (open enveloped data)                                               */
/* -------------------------------------------------------------------------- */
export async function decryptMessage(
  mime: string,
  recipientKey: forge.pki.PrivateKey,
  caCerts: forge.pki.Certificate[] = []
): Promise<string> {
  const { body } = parseMime(mime);
  const der = forge.util.decode64(body);
  const cms = forge.cms.readEnvelopedData(der);

  // Provide the private key for the recipient
  const recipients = cms.recipientInfos.filter(info => {
    // node‑forge does not expose a direct API to match a key; we simply try each
    return true;
  });

  // Try each recipient until one works
  for (const recipient of cms.recipientInfos) {
    try {
      // Decrypt using the supplied private key (must correspond to the recipient)
      const plain = recipient.decrypt(recipientKey);
      return plain as string;
    } catch {
      continue;
    }
  }
  throw new Error('Decryption failed – no matching private key found');
}

/* -------------------------------------------------------------------------- */
/* Verify (check signed data)                                                  */
/* -------------------------------------------------------------------------- */
export interface VerificationResult {
  valid: boolean;
  errors: string[];
  signerCert?: forge.pki.Certificate;
  signerInfo?: forge.cms.SignerInfo;
}

/**
 * Verifies a MIME‑wrapped PKCS#7 signed message.
 * Returns an object with validation status, any error messages,
 * and the signer certificate / signer info if verification succeeds.
 */
export async function verifyMessage(
  mime: string,
  trustAnchors: forge.pki.Certificate[] = []
): Promise<VerificationResult> {
  const { body } = parseMime(mime);
  const der = forge.util.decode64(body);
  const cms = forge.cms.readSignedData(der);

  const errors: string[] = [];

  // 1. Validate the signature chain
  try {
    cms.verify({ trustedCerts: trustAnchors });
  } catch (e: any) {
    errors.push(`Signature verification failed: ${e.message}`);
  }

  // 2. Extract signer certificate(s)
  const signerInfos = cms.signerInfos;
  if (signerInfos.length === 0) {
    errors.push('No signer information found in CMS.');
  }

  // 3. Check certificate expiration / basic constraints (basic)
  const cert = signerInfos[0]?.certificate;
  if (cert) {
    const now = new Date();
    if (now < cert.validity.notBefore) {
      errors.push('Signer certificate not yet valid.');
    }
    if (now > cert.validity.notAfter) {
      errors.push('Signer certificate expired.');
    }
    // Basic constraints – leaf should have cA = false
    const basicConstraints = cert.getExtension('basicConstraints');
    if (basicConstraints && basicConstraints.cA) {
      errors.push('Signer certificate is a CA – unexpected for end‑entity.');
    }
  }

  const result: VerificationResult = {
    valid: errors.length === 0,
    errors,
    signerCert: cert,
    signerInfo: signerInfos[0],
  };
  return result;
}

/* -------------------------------------------------------------------------- */
/* Convenience: load CA & leaf certs from files (used by demos)                */
/* -------------------------------------------------------------------------- */
export function loadDemoCerts() {
  const caCert = loadCertificateFromFile(path.resolve(__dirname, '../ca.pem'));
  const leafCert = loadCertificateFromFile(path.resolve(__dirname, '../leaf.pem'));
  const leafKey = loadPrivateKeyFromFile(path.resolve(__dirname, '../leaf.key.pem'));
  return { caCert, leafCert, leafKey };
}
```

## 🎬 src/demoRoundtrip.ts – Sign‑Then‑Encrypt, Decrypt & Verify

```ts
import { loadDemoCerts, signMessage, encryptMessage, decryptMessage, verifyMessage } from './smime';

async function main() {
  const { caCert, leafCert, leafKey } = loadDemoCerts();

  const originalPayload = 'Hello, this is the secret message.';

  console.log('=== Sign‑Then‑Encrypt Round‑Trip Demo ===\n');

  // 1️⃣ Sign the payload (leaf signs, CA is trusted anchor)
  console.log('1️⃣ Signing payload with leaf certificate...');
  const signedMime = await signMessage(originalPayload, { cert: leafCert, key: leafKey }, [caCert]);
  console.log('   Signed MIME (first 80 chars):', signedMime.slice(0, 80), '...');

  // 2️⃣ Encrypt the signed MIME (encrypt for the same leaf)
  console.log('\n2️⃣ Encrypting signed payload for leaf recipient...');
  const encryptedMime = await encryptMessage(signedMime, leafCert, [caCert]);
  console.log('   Encrypted MIME (first 80 chars):', encryptedMime.slice(0, 80), '...');

  // 3️⃣ Decrypt (leaf uses its private key)
  console.log('\n3️⃣ Decrypting (leaf private key)...');
  const decryptedMime = await decryptMessage(encryptedMime, leafKey, [caCert]);
  console.log('   Decrypted MIME (first 80 chars):', decryptedMime.slice(0, 80), '...');

  // 4️⃣ Verify the inner signed payload
  console.log('\n4️⃣ Verifying inner signature (trust anchor = CA)...');
  const verification = await verifyMessage(decryptedMime, [caCert]);

  if (verification.valid) {
    console.log('   ✅ Signature is VALID.');
    console.log('   📜 Signer certificate subject:', verification.signerCert?.subject);
    console.log('   📜 Original payload recovered:', verification.signerCert ? originalPayload : '(unknown)');
  } else {
    console.log('   ❌ Signature INVALID:', verification.errors.join('; '));
  }

  console.log('\n=== Demo complete ===');
}

main().catch(err => {
  console.error('Demo failed:', err);
  process.exit(1);
});
```

## 🧪 src/demoTamper.ts – Tampered‑Message Detection

```ts
import { loadDemoCerts, signMessage, encryptMessage, decryptMessage, verifyMessage } from './smime';

async function main() {
  const { caCert, leafCert, leafKey } = loadDemoCerts();

  const originalPayload = 'Confidential data.';
  console.log('=== Tampered‑Message Fixture Demo ===\n');

  // 1️⃣ Normal sign‑then‑encrypt (as before)
  const signedMime = await signMessage(originalPayload, { cert: leafCert, key: leafKey }, [caCert]);
  const encryptedMime = await encryptMessage(signedMime, leafCert, [caCert]);

  // 2️⃣ Tamper with the encrypted MIME body (flip a random byte)
  const { body } = parseMime(encryptedMime);
  const binary = forge.util.decode64(body);
  const arr = new Uint8Array(binary);
  // Flip the first byte (any non‑zero byte works)
  arr[0] ^= 0xFF;
  const tamperedBinary = Buffer.from(arr);
  const tamperedBody = forge.util.encode64(tamperedBinary);
  const tamperedMime = buildMime(parseMime(encryptedMime).headers, tamperedBody);

  console.log('2️⃣ Encrypted payload has been tampered (first byte flipped).');

  // 3️⃣ Attempt decryption – should raise an error
  try {
    const decrypted = await decryptMessage(tamperedMime, leafKey, [caCert]);
    console.log('   ⚠️  Decryption unexpectedly succeeded (tampered payload accepted).');
  } catch (e: any) {
    console.log('   ✅ Decryption failed as expected:', e.message);
  }

  // 4️⃣ Attempt verification of the *original* signed payload (still valid)
  console.log('\n3️⃣ Verifying the *original* (untampered) signed payload...');
  const verification = await verifyMessage(signedMime, [caCert]);
  if (verification.valid) {
    console.log('   ✅ Original signature remains valid.');
  } else {
    console.log('   ❌ Unexpected verification failure:', verification.errors.join('; '));
  }

  console.log('\n=== Tamper demo complete ===');
}

// Re‑export parseMime & buildMime for this demo
import { parseMime, buildMime } from './smime';

main().catch(err => {
  console.error('Tamper demo failed:', err);
  process.exit(1);
});
```

**Typical output:**

```
=== Tampered‑Message Fixture Demo ===

2️⃣ Encrypted payload has been tampered (first byte flipped).

   ✅ Decryption failed as expected: Decryption failed – no matching private key found

3️⃣ Verifying the *original* (untampered) signed payload...
   ✅ Original signature remains valid.

=== Tamper demo complete ===
```

The decryption failure demonstrates that **integrity protection** is provided by the encryption layer, while the signature verification still works on the untouched signed payload.

## 📚 README / Usage Instructions

1. **Clone the repository** (or copy the files into a folder).

2. **Install dependencies** (exact versions from `package.json`):

   ```bash
   npm install
   ```

3. **Generate test certificates** (once):

   ```bash
   npm run certs
   ```

   *This creates `ca.pem`, `ca.key.pem`, `leaf.pem`, and `leaf.key.pem` in the project root.*

4. **Build the TypeScript code**:

   ```bash
   npm run build
   ```

5. **Run the full demo suite** (sign‑then‑encrypt round‑trip + tamper detection):

   ```bash
   npm run test
   ```

   - `npm run demo:roundtrip` – shows a successful sign‑then‑encrypt/decrypt/verify flow.  
   - `npm run demo:tamper` – shows how a tampered encrypted payload is caught.

6. **Inspect the generated MIME** (optional):

   ```bash
   # Example: view the signed MIME part
   cat dist/demoRoundtrip.js | grep -A5 'Signed MIME'
   ```

   For a more readable view, you can add a small helper to pretty‑print the MIME in the console, but the core logic above already logs the first 80 characters.

## 🛡️ Error Handling & Classification

The utility distinguishes three categories of failures:

| Category | When it occurs | Example error message |
|----------|----------------|-----------------------|
| **Signature errors** | `cms.verify` throws, missing signer info, bad signature | `"Signature verification failed: Invalid signature"` |
| **Certificate errors** | Expired cert, CA‑cert used as end‑entity, missing basicConstraints | `"Signer certificate expired."` |
| **Content errors** | Decryption fails (wrong key, corrupted ciphertext), malformed MIME | `"Decryption failed – no matching private key found"` |

All errors are collected in the `VerificationResult.errors` array, allowing callers to present fine‑grained feedback.
