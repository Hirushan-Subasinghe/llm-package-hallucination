Below is a **complete, self‑contained Node.js + TypeScript SOAP interoperability example** that demonstrates:

* **WS‑Security UsernameToken** (password digest, nonce, timestamp)
* **X.509 XML‑DSIG signatures** (client‑signed request, server‑signed response)
* **Replay‑attack protection** (in‑memory nonce cache)
* **MTOM / XOP binary attachment** (one file transferred as a separate MIME part)
* **SOAP fault handling** (invalid credentials, replay, signature errors)
* **Namespace and reference validation** (signatures, attachment CID, content hash)

The example is deliberately **minimal** – it focuses on the exact WSDL, security, and multipart integration points rather than a full‑blown platform.

cert.validity.notBefore = new Date();
cert.validity.notAfter = new Date();

fs.writeFileSync(path.join(certsDir, 'server.crt'), certPem);

## 🖥️ `src/server/index.ts`

```ts
import express, { Request, Response, NextFunction } from 'express';
import * as soap from 'node-soap';
import * as fs from 'fs';
import * as path from 'path';
import * as xml2js from 'xml2js';
import * as crypto from 'crypto';
import * as xmlCrypto from 'xml-crypto';
import * as forge from 'node-forge';
import { v4 as uuidv4 } from 'uuid';

// Load the WSDL
const wsdlPath = path.join(__dirname, '..', 'wsdl', 'sample.wsdl');
const wsdl = fs.readFileSync(wsdlPath, 'utf8');

// Load server certificate & key (used for response signing)
const serverCertPem = fs.readFileSync(path.join(__dirname, '..', 'certs', 'server.crt'), 'utf8');
const serverKeyPem = fs.readFileSync(path.join(__dirname, '..', 'certs', 'server.key'), 'utf8');

// In‑memory replay cache: nonce+created → timestamp
const replayCache = new Map<string, number>();
const REPLAY_WINDOW_MS = 5 * 60 * 1000; // 5 minutes

/* -------------------------------------------------------------------------- */
/* Helper: XML ↔ JS (xml2js)                                                  */
/* -------------------------------------------------------------------------- */
const parseXml = (xml: string) =>
  new Promise<any>((resolve, reject) => {
    xml2js.parseString(xml, { explicitArray: false, ignoreAttrs: false }, (err, result) => {
      if (err) reject(err);
      else resolve(result);
    });
  });

const buildXml = (obj: any) => {
  const builder = new xml2js.Builder({ explicitArray: false, ignoreAttrs: false });
  return builder.buildObject(obj);
};

/* -------------------------------------------------------------------------- */
/* Security validation (UsernameToken, X.509 signature, timestamp, replay)      */
/* -------------------------------------------------------------------------- */
const validateSecurity = async (req: express.Request, envelopeXml: string) => {
  const envelope = await parseXml(envelopeXml) as any;
  const header = envelope.Envelope.Header || {};

  // WS‑Security header (prefix may be wsse: or wsu:)
  const secHeader = header['wsse:Security'] || header['wsu:Security'];
  if (!secHeader) throw new Error('Missing WS‑Security header');

  // ----- UsernameToken -----
  const usernameToken = secHeader['wsse:UsernameToken'];
  if (!usernameToken) throw new Error('Missing UsernameToken');

  const username = usernameToken['wsse:Username'];
  const passwordDigest = usernameToken['wsse:Password'];
  const nonce = usernameToken['wsse:Nonce'];
  const timestamp = usernameToken['wsu:Timestamp'] || secHeader['wsu:Timestamp'];

  // Hard‑coded credentials for demo
  const EXPECTED_USER = 'alice';
  const EXPECTED_PASS = 'password';

  if (username !== EXPECTED_USER) throw new Error('Invalid username');
  const created = timestamp && timestamp['wsu:Created'];
  if (!created) throw new Error('Missing Created timestamp in UsernameToken');

  // Password digest = base64(sha1(nonce + created + password))
  const digest = crypto.createHash('sha1')
    .update(Buffer.from(nonce, 'base64'))
    .update(Buffer.from(created, 'utf8'))
    .update(EXPECTED_PASS)
    .digest();
  const computedDigest = Buffer.from(digest).toString('base64');
  if (computedDigest !== passwordDigest) throw new Error('Invalid password digest');

  // Replay protection
  const replayKey = `${nonce}:${created}`;
  const now = Date.now();
  if (replayCache.has(replayKey)) {
    const firstSeen = replayCache.get(replayKey)!;
    if (now - firstSeen < REPLAY_WINDOW_MS) {
      throw new Error('Replay attack detected');
    }
  }
  replayCache.set(replayKey, now);

  // ----- X.509 Signature -----
  const signature = secHeader['ds:Signature'] || secHeader['Signature'];
  if (!signature) throw new Error('Missing XML signature');

  // Extract certificate from ds:X509Data (inline in the signature)
  const x509Data = signature['ds:X509Data'] || signature['X509Data'];
  if (!x509Data) throw new Error('Signature contains no X.509 data');
  const certNode = x509Data['ds:X509Certificate'] || x509Data['X509Certificate'];
  if (!certNode) throw new Error('X.509 certificate missing in signature');

  // Verify signature over the *original* envelope (including security header)
  const sig = new xmlCrypto.Signature(buildXml(signature));
  const cert = forge.pki.certificateFromPem(certNode);
  const isValid = sig.verify(envelopeXml, cert.publicKey);
  if (!isValid) throw new Error('XML signature verification failed');

  // ----- Timestamp sanity (optional) -----
  if (created) {
    const ts = new Date(created);
    if (Math.abs(Date.now() - ts.getTime()) > REPLAY_WINDOW_MS) {
      throw new Error('Timestamp outside acceptable window');
    }
  }

  return { username, created };
};

/* -------------------------------------------------------------------------- */
/* Sign an XML document with an X.509 certificate (node‑forge)                */
/* -------------------------------------------------------------------------- */
const signXml = async (xml: string, certPem: string, keyPem: string): Promise<string> => {
  const cert = forge.pki.certificateFromPem(certPem);
  const key = forge.pki.privateKeyFromPem(keyPem);

  const signature = new xmlCrypto.Signature({
    signatureAlgorithm: 'sha256',
    digestAlgorithm: 'sha256',
    canonicalizationAlgorithm: 'c14n',
    id: `sig-${uuidv4()}`,
  });

  // Sign the whole document (xpath '/' means the document node)
  signature.addReference(
    xml,
    { xpath: '/', digestAlgorithm: 'sha256' },
    { embed: true } // embed the certificate in the Signature
  );

  signature.signingKey = key;
  signature.keyInfoProvider = {
    getKeyInfo: () => `<ds:X509Data>${forge.pki.certificateToPem(cert)}</ds:X509Data>`,
    getPublicKey: () => cert.publicKey,
  };

  return signature.getSignedXml(xml);
};

/* -------------------------------------------------------------------------- */
/* SOAP service definition (single operation)                               */
/* -------------------------------------------------------------------------- */
const service = {
  ProcessService: {
    ProcessServicePort: {
      ProcessData: async (args: any, callback: any, req: express.Request, res: express.Response) => {
        try {
          // The MTOM plugin puts the raw SOAP envelope into req.body (string)
          const envelopeXml = typeof req.body === 'string' ? req.body : JSON.stringify(req.body);

          // 1️⃣ Validate security (UsernameToken, X.509, replay, timestamp)
          await validateSecurity(req, envelopeXml);

          // 2️⃣ Parse envelope to obtain operation input & attachments
          const envelope = await parseXml(envelopeXml) as any;
          const body = envelope.Envelope.Body;
          const input = body['ns:ProcessData'] || body['ProcessData'];
          const data = input?.Data;
          const attachments = req.attachments || [];

          // 3️⃣ Process binary attachment (if any)
          let attachmentInfo = '';
          if (attachments.length > 0) {
            const att = attachments[0];
            const content = att.content as Buffer;
            const contentId = att.headers['content-id'] || 'unknown';
            const hash = crypto.createHash('sha256').update(content).digest('base64');
            attachmentInfo = `CID:${contentId} SHA256:${hash} Size:${content.length}`;
          }

          // Simulate business logic
          const result = `Processed "${data}" ${attachmentInfo}`.trim();

          // 4️⃣ Build response SOAP envelope (no MTOM needed for the reply)
          const responseEnvelope = {
            Envelope: {
              $: {
                'xmlns:soap': 'http://schemas.xmlsoap.org/soap/envelope/',
                'xmlns:ns': 'http://example.com/sample',
                'xmlns:wsse': 'http://docs.oasis-open.org/wss/2004/08/wss/vocabularies/types',
                'xmlns:wsu': 'http://docs.oasis-open.org/wss/2004/08/wss/vocabularies/types',
                'xmlns:ds': 'http://www.w3.org/2000/01/xmldsig#',
              },
              Header: {
                'wsse:Security': {
                  'wsu:Timestamp': { 'wsu:Created': new Date().toISOString() },
                  // The signature element will be filled after signing
                  'ds:Signature': {}
                }
              },
              Body: {
                'ns:ProcessDataResponse': {
                  Result: result,
                }
              }
            }
          };

          const responseXml = buildXml(responseEnvelope);
          const signedResponseXml = await signXml(responseXml, serverCertPem, serverKeyPem);

          // Send signed response
          res.set('Content-Type', 'text/xml');
          res.send(signedResponseXml);
          callback(null, signedResponseXml);
        } catch (err) {
          const error = err as Error;
          // Build a SOAP fault (namespaces are important for interoperability)
          const faultEnvelope = {
            Envelope: {
              $: {
                'xmlns:soap': 'http://schemas.xmlsoap.org/soap/envelope/',
                'xmlns:ns': 'http://example.com/sample',
              },
              Body: {
                Fault: {
                  faultcode: 'soap:Client',
                  faultstring: error.message,
                  detail: '',
                }
              }
            }
          };
          const faultXml = buildXml(faultEnvelope);
          res.status(500).set('Content-Type', 'text/xml').send(faultXml);
          callback(error);
        }
      }
    }
  }
};

/* -------------------------------------------------------------------------- */
/* Start the server (Express + node‑soap with MTOM)                           */
/* -------------------------------------------------------------------------- */
const app = express();

// Raw body is needed for MTOM multipart parsing (node‑soap will populate req.attachments)
app.use(express.json({ strict: false, verify: (req, res, buf) => { req.rawBody = buf; } }));

// node‑soap listens on /process and automatically parses MTOM when the option is set
soap.listen(app, '/process', wsdl, service, { mtom: true });

const PORT = 8080;
app.listen(PORT, () => {
  console.log(`🚀 SOAP server listening on http://localhost:${PORT}/process`);
});
```

**Key points in the server**

* **Security validation** (`validateSecurity`) extracts the UsernameToken, computes the password digest, checks replay, and verifies the X.509 signature using `xml-crypto`.  
* **Replay cache** is a simple `Map<string, number>` that stores `nonce:created` and rejects duplicates within a 5‑minute window.  
* **MTOM handling** – `node-soap` with `{ mtom: true }` automatically parses the multipart request and attaches the binary part(s) to `req.attachments`.  
* **Response signing** – the server signs the response envelope with its own X.509 cert/key (`server.crt` / `server.key`). The certificate is embedded in the `<ds:Signature>` via `keyInfoProvider`.  
* **SOAP fault** – any validation error results in a fault with proper `soap:Client` code and a human‑readable `faultstring`. The fault envelope includes the required SOAP namespaces.

## 📲 `src/client/index.ts`

```ts
import * as http from 'http';
import * as fs from 'fs';
import * as path from 'path';
import * as xml2js from 'xml2js';
import * as crypto from 'crypto';
import * as xmlCrypto from 'xml-crypto';
import * as forge from 'node-forge';
import { v4 as uuidv4 } from 'uuid';

// Load client certificate & key (same cert/key as server for this demo)
const clientCertPem = fs.readFileSync(path.join(__dirname, '..', '..', 'certs', 'client.crt'), 'utf8');
const clientKeyPem = fs.readFileSync(path.join(__dirname, '..', '..', 'certs', 'client.key'), 'utf8');

// Load server certificate (for response verification)
const serverCertPem = fs.readFileSync(path.join(__dirname, '..', '..', 'certs', 'server.crt'), 'utf8');

/* -------------------------------------------------------------------------- */
/* XML helpers (same as server)                                               */
/* -------------------------------------------------------------------------- */
const parseXml = (xml: string) =>
  new Promise<any>((resolve, reject) => {
    xml2js.parseString(xml, { explicitArray: false, ignoreAttrs: false }, (err, result) => {
      if (err) reject(err);
      else resolve(result);
    });
  });

const buildXml = (obj: any) => {
  const builder = new xml2js.Builder({ explicitArray: false, ignoreAttrs: false });
  return builder.buildObject(obj);
};

/* -------------------------------------------------------------------------- */
/* Build the request envelope (with security header & X.509 signature)         */
/* -------------------------------------------------------------------------- */
const buildRequestEnvelope = async (data: string, attachmentBuffer?: Buffer) => {
  // 1️⃣ UsernameToken (hard‑coded credentials)
  const nonce = crypto.randomBytes(16).toString('base64');
  const created = new Date().toISOString();
  const password = 'password';
  const digest = crypto.createHash('sha1')
    .update(Buffer.from(nonce, 'base64'))
    .update(Buffer.from(created, 'utf8'))
    .update(password)
    .digest();
  const passwordDigest = Buffer.from(digest).toString('base64');

  const usernameToken = {
    'wsse:UsernameToken': {
      'wsse:Username': 'alice',
      'wsse:Password': {
        $: { Type: 'http://docs.oasis-open.org/wss/2004/08/wss/vocabularies/types#PasswordDigest' },
        '#text': passwordDigest,
      },
      'wsse:Nonce': nonce,
      'wsu:Timestamp': { 'wsu:Created': created },
    },
  };

  // 2️⃣ Operation body (include XOP reference if an attachment is present)
  const body = {
    'ns:ProcessData': {
      Data: data,
      ...(attachmentBuffer ? { Attachment: { $: { 'xop:href': 'cid:attachment@123' } } : {}),
    },
  };

  // 3️⃣ Assemble envelope (unsigned for now)
  const envelope = {
    Envelope: {
      $: {
        'xmlns:soap': 'http://schemas.xmlsoap.org/soap/envelope/',
        'xmlns:ns': 'http://example.com/sample',
        'xmlns:wsse': 'http://docs.oasis-open.org/wss/2004/08/wss/vocabularies/types',
        'xmlns:wsu': 'http://docs.oasis-open.org/wss/2004/08/wss/vocabularies/types',
        'xmlns:ds': 'http://www.w3.org/2000/01/xmldsig#',
        'xmlns:xop': 'http://www.w3.org/2004/08/xop/include',
      },
      Header: usernameToken,
      Body: body,
    },
  };

  const envelopeXml = buildXml(envelope);

  // 4️⃣ Sign the envelope with the client's X.509 cert
  const signedEnvelopeXml = await signXml(envelopeXml, clientCertPem, clientKeyPem);

  // 5️⃣ If an attachment is present, wrap the whole thing in a multipart/related message
  if (attachmentBuffer) {
    const boundary = `----=_Part_${Date.now()}`;
    const contentType = `multipart/related; boundary="${boundary}"; type="application/xop+xml"; start="<soap-envelope>"; charset=UTF-8;`;

    // Build multipart body (simplified – each part ends with \r\n)
    const parts = [
      `--${boundary}`,
      `Content-Type: application/xop+xml; charset=UTF-8; type="text/xml";`,
      `Content-Transfer-Encoding: binary`,
      `Content-ID: <soap-envelope>`,
      '',
      signedEnvelopeXml,
      '',
      `--${boundary}`,
      `Content-Type: application/octet-stream`,
      `Content-Transfer-Encoding: binary`,
      `Content-ID: <attachment@123>`,
      '',
      attachmentBuffer.toString('base64'), // base64‑encoded binary for the demo
      '',
      `--${boundary}--`,
      '',
    ];
    const multipartBody = parts.join('\r\n');

    return { xml: multipartBody, contentType };
  }

  return { xml: signedEnvelopeXml, contentType: 'text/xml' };
};

/* -------------------------------------------------------------------------- */
/* Sign XML with X.509 (node‑forge)                                           */
/* -------------------------------------------------------------------------- */
const signXml = async (xml: string, certPem: string, keyPem: string): Promise<string> => {
  const cert = forge.pki.certificateFromPem(certPem);
  const key = forge.pki.privateKeyFromPem(keyPem);

  const signature = new xmlCrypto.Signature({
    signatureAlgorithm: 'sha256',
    digestAlgorithm: 'sha256',
    canonicalizationAlgorithm: 'c14n',
    id: `sig-${uuidv4()}`,
  });

  signature.addReference(
    xml,
    { xpath: '/', digestAlgorithm: 'sha256' },
    { embed: true }
  );

  signature.signingKey = key;
  signature.keyInfoProvider = {
    getKeyInfo: () => `<ds:X509Data>${forge.pki.certificateToPem(cert)}</ds:X509Data>`,
    getPublicKey: () => cert.publicKey,
  };

  return signature.getSignedXml(xml);
};

/* -------------------------------------------------------------------------- */
/* Verify a response signature (using the server's public key)                */
/* -------------------------------------------------------------------------- */
const verifyResponseSignature = async (responseXml: string, certPem: string): Promise<boolean> => {
  const envelope = await parseXml(responseXml) as any;
  const header = envelope.Envelope.Header || {};
  const secHeader = header['wsse:Security'] || header['wsu:Security'];
  const signature = secHeader && (secHeader['ds:Signature'] || secHeader['Signature']);
  if (!signature) return false;

  const sig = new xmlCrypto.Signature(buildXml(signature));
  const cert = forge.pki.certificateFromPem(certPem);
  return sig.verify(responseXml, cert.publicKey);
};

/* -------------------------------------------------------------------------- */
/* Send the request and process the response                                   */
/* -------------------------------------------------------------------------- */
const sendRequest = async (data: string, attachmentBuffer?: Buffer) => {
  const { xml, contentType } = await buildRequestEnvelope(data, attachmentBuffer);

  const options = {
    hostname: 'localhost',
    port: 8080,
    path: '/process',
    method: 'POST',
    headers: {
      'Content-Type': contentType,
      'Content-Length': Buffer.byteLength(xml),
    },
  };

  return new Promise<string>(async (resolve, reject) => {
    const req = http.request(options, async (res) => {
      let responseBody = '';
      res.on('data', (chunk) => { responseBody += chunk; });
      res.on('end', async () => {
        try {
          // Verify response signature
          const valid = await verifyResponseSignature(responseBody, serverCertPem);
          if (!valid) throw new Error('Response signature verification failed');

          // Parse response to extract the Result
          const envelope = await parseXml(responseBody) as any;
          const body = envelope.Envelope.Body;
          const result = body['ns:ProcessDataResponse']?.Result;
          resolve(result);
        } catch (err) {
          reject(err);
        }
      });
    });

    req.on('error', reject);
    req.write(xml);
    req.end();
  });
};

/* -------------------------------------------------------------------------- */
/* Example usage (run this file with `ts-node src/client/index.ts`)            */
/* -------------------------------------------------------------------------- */
(async () => {
  // Create a tiny PNG as the binary attachment (base64 decoded)
  const attachmentBuffer = Buffer.from(
    'iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNkYPhfDwAChwGA60e6kgAAAABJRU5ErkJggg==',

```

**Key points in the client**

* **UsernameToken** – builds the nonce, Created timestamp, and password digest exactly as the server expects.  
* **X.509 signature** – signs the whole envelope (including the security header) with the client’s certificate (`client.crt` / `client.key`). The certificate is embedded in the `<ds:Signature>`.  
* **MTOM** – if an attachment is supplied, the client manually builds a `multipart/related` payload with the SOAP envelope as the root (`Content-ID: <soap-envelope>`) and the binary file as a separate part (`Content-ID: <attachment@123>`).  The request’s `Content-Type` reflects the multipart boundary.  
* **Response verification** – after receiving the reply, the client extracts the `<ds:Signature>` from the response’s security header, verifies it against the server’s public key (`server.crt`), and finally extracts the `Result` from the SOAP body.

This repository demonstrates a **self‑contained Node.js + TypeScript** SOAP service that:

* Uses a **small WSDL** (`src/wsdl/sample.wsdl`) defining a single `ProcessData` operation.

* Transfers a **binary attachment** using **MTOM/XOP** (multipart/related) instead of inline base64.
* Validates **SOAP faults**, **namespaces**, **signature references**, **attachment CID**, and **content hash**.
