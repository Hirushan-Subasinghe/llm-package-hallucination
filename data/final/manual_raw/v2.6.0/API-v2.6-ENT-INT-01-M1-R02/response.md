**Project Overview**

The project is a self‑contained Node.js TypeScript service for parsing X12 850 purchase orders, validating control numbers, mapping parties and line items into typed JSON, and generating a 997 functional acknowledgment. It includes fixtures (valid/invalid 850 files), round‑trip examples, and a complete package.json with exact dependency versions.

Below are the key components and how to run everything.

---

### 📦 Installation & Setup

1 . Clone the repository.
 . Ensure Node.js ≥ 18 is installed.
 . Run the build step (type checking + compilation):

```bash
npm install          # installs all dependencies
npm run build        # compiles TypeScript to dist/
```

> **Note:** The `package.json` scripts are defined to support development, testing, linting, and the actual functionality.

---

### 📂 Project Structure

```
src/
├── models.ts                # TypeScript interfaces for X12, PurchaseOrder, etc.
├── parser.ts                # Wraps edi-x12, returns ParsedX12 and ValidationError[]
├── validator.ts              # Validates ISA/GS/ST control numbers and segment counts
├── mapper.ts                 # Maps GSTransactionSet → PurchaseOrder JSON
├── ackGenerator.ts           # Generates 997 using edi-x12::buildX12
├── cli.ts                    # Command‑line interface (parse, validate, map, ack, roundtrip)
└── utils.ts                  # Helper functions (toLibraryShape, etc.)

fixtures/
├── valid850.txt
├── invalid850.txt
└── valid850.json   # Expected PurchaseOrder JSON

test/
├── parser.spec.ts
├── validator.spec.ts
└── ackGenerator.spec.ts

dist/                     # Generated by `tsc`
.gitignore
package.json
tsconfig.json
README.md
```
