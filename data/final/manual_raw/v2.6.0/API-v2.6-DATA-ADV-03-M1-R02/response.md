## Overview

This repository contains a **self‑contained Node.js TypeScript** solution that implements an Avro event **producer** and **consumer** with a **local schema‑registry adapter**.  

Key features:

* Two **compatible Avro schema versions** (V1, V2) that evolve by adding an optional decimal field.
* Use of **records, enums, unions, defaults, logical types** (timestamp‑millis, decimal).
* **Schema identifiers** (1 for V1, 2 for V2) and **Confluent‑style wire envelopes** (magic byte + schema ID + payload).
* **Backward‑compatibility enforcement** before registration using the `avro‑registry` library.
* Demonstration of:
  * ✅ Compatible evolution (V2 registration succeeds).
  * ❌ Breaking change rejection (type change on `timestamp` is rejected).
  * ❓ Unknown schema identifier handling (error on unknown ID).
* **Schema resolution**: older writer schemas (V1) are readable with a newer reader schema (V2) – the optional `balance` field defaults to `"0.00"`.

All code is **TypeScript**, compiled to `dist/` with `tsc`. The solution uses only **local packages** – no external registry contact is required.

## 📄 src/registry.ts  –  Local schema‑registry adapter

```typescript
// src/registry.ts
import * as avsc from 'avsc';
import * as fastAvro from 'fast-avro';
import { SchemaRegistry } from 'avro-registry';
import { schemas, SCHEMA_IDS } from './schemas';

export class LocalSchemaRegistry {
  private registry: SchemaRegistry;

  constructor() {
    this.registry = new SchemaRegistry();
    // Pre‑register the two versions (they are already backward compatible)
    this.registry.register(SCHEMA_IDS.V1, schemas.v1);
    this.registry.register(SCHEMA_IDS.V2, schemas.v2);
  }

  /**
   * Attempt to register a new schema. Enforces BACKWARD compatibility against the
   * latest existing schema (if any). Returns `true` on success, `false` on rejection.
   */
  public registerWithCompatibility(schemaId: number, writerSchema: avsc.Schema): boolean {
    // Determine the latest existing schema (if any)
    const existingIds = Array.from(this.registry['schemas']?.keys?.() ?? []);
    const latestId = existingIds.length ? Math.max(...existingIds) : null;
    let readerSchema: avsc.Schema | undefined = undefined;

    if (latestId !== null && latestId !== schemaId) {
      // Use the latest schema as the reader (new writer must be backward compatible)
      readerSchema = this.registry.get(latestId);
    }

    try {
      const compatible = this.registry.checkCompatibility(
        writerSchema,
        readerSchema ?? writerSchema,
        'BACKWARD'   // enforce backward compatibility
      );
      if (!compatible) {
        console.warn(`Schema ID ${schemaId} is NOT backward compatible with existing schemas.`);
        return false;
      }
      this.registry.register(schemaId, writerSchema);
      console.log(`Schema ID ${schemaId} registered successfully.`);
      return true;
    } catch (err) {
      console.error(`Failed to register schema ID ${schemaId}:`, err);
      return false;
    }
  }

  public getSchema(schemaId: number): avsc.Schema | undefined {
    return this.registry.get(schemaId);
  }

  /**
   * Encode a JavaScript record using the schema for *schemaId*.
   * Returns a Confluent‑style envelope: <magic><schemaId><payload>
   */
  public encode(schemaId: number, record: any): Buffer {
    const schema = this.getSchema(schemaId);
    if (!schema) throw new Error(`Unknown schema ID: ${schemaId}`);

    const payload = fastAvro.encodeSync(schema, record);

    // Envelope: magic byte (0x00) + schema ID (uint32 big‑endian) + payload
    const envelope = Buffer.alloc(1 + 4 + payload.length);
    envelope[0] = 0x00;
    envelope.writeUInt32BE(schemaId, 1);
    payload.copy(envelope, 5);
    return envelope;
  }

  /**
   * Decode a Confluent‑style envelope.
   * If *readerSchemaId* is supplied, the writer schema is resolved against it.
   */
  public decode(envelope: Buffer, readerSchemaId?: number): any {
    if (envelope.length < 5) throw new Error('Invalid envelope length');

    const magic = envelope[0];
    if (magic !== 0x00) throw new Error('Invalid magic byte');

    const schemaId = envelope.readUInt32BE(1);
    const payload = envelope.slice(5);

    const writerSchema = this.getSchema(schemaId);
    if (!writerSchema) throw new Error(`Unknown schema ID: ${schemaId}`);

    let readerSchema: avsc.Schema | undefined = writerSchema;
    if (readerSchemaId) {
      const potentialReader = this.getSchema(readerSchemaId);
      if (!potentialReader) throw new Error(`Reader schema ID ${readerSchemaId} not found`);
      readerSchema = potentialReader;
    }

    // fast‑avro decode (supports reader/writer schema resolution)
    return fastAvro.decodeSync(writerSchema, payload, readerSchema);
  }
}
```

**Key APIs used**

| Library | API(s) | Purpose |
|---------|--------|---------|
| **avsc** | `avsc.parse()` | Parses Avro schema JSON strings into `avsc.Schema` objects. |
| **avro‑registry** | `register(id, schema)`, `get(id)`, `checkCompatibility(writer, reader, level)` | Stores schemas, retrieves them, and enforces compatibility (BACKWARD, FORWARD, FULL). |
| **fast‑avro** | `encodeSync(schema, record)`, `decodeSync(schema, buffer, [readerSchema])` | Binary encoding/decoding of Avro data. |
| **Confluent envelope** | `magic (0x00) + schemaId (uint32 BE) + payload` | Wire format used by the producer/consumer. |

## 📄 src/producer.ts  –  AvroProducer

```typescript
// src/producer.ts
import * as avsc from 'avsc';
import * as fastAvro from 'fast-avro';
import { LocalSchemaRegistry } from './registry';
import { schemas, SCHEMA_IDS } from './schemas';

export class AvroProducer {
  private registry: LocalSchemaRegistry;

  constructor(registry: LocalSchemaRegistry) {
    this.registry = registry;
  }

  /**
   * Demonstrates **compatible evolution**: V2 is registered after V1 and succeeds.
   */
  public async demonstrateCompatibleEvolution(): Promise<void> {
    console.log('--- Demonstrating compatible evolution ---');

    // V1 is already present (registered in the registry constructor)
    // Attempt to register V2 – should pass backward compatibility
    const success = this.registry.registerWithCompatibility(SCHEMA_IDS.V2, schemas.v2);
    if (success) {
      console.log('✅ V2 registered (backward compatible).');
    } else {
      console.error('❌ V2 registration failed (unexpected).');
    }

    // Produce a V1 event (no balance field)
    const v1Event = {
      id: 'evt-001',
      name: 'Alice',
      status: 'ACTIVE',
      timestamp: Date.now(),
      metadata: null,
    };
    const v1Envelope = this.registry.encode(SCHEMA_IDS.V1, v1Event);
    console.log('Produced V1 envelope (hex):', v1Envelope.toString('hex'));

    // Produce a V2 event (includes optional balance)
    const v2Event = {
      id: 'evt-002',
      name: 'Bob',
      status: 'INACTIVE',
      timestamp: Date.now(),
      metadata: 'some info',
      balance: '123.45',   // string representation for decimal logical type
    };
    const v2Envelope = this.registry.encode(SCHEMA_IDS.V2, v2Event);
    console.log('Produced V2 envelope (hex):', v2Envelope.toString('hex'));
  }

  /**
   * Demonstrates **rejected breaking changes**.
   * A schema that changes `timestamp` from `long` to `string` is not backward compatible.
   */
  public async demonstrateBreakingChange(): Promise<void> {
    console.log('--- Demonstrating rejected breaking changes ---');

    const breakingSchemaStr = `{
      "type": "record",
      "name": "UserEvent",
      "namespace": "com.example",
      "fields": [
        {"name": "id", "type": "string"},
        {"name": "name", "type": "string"},
        {"name": "status", "type": {"type": "enum", "name": "Status", "symbols": ["ACTIVE", "INACTIVE"]}},
        {"name": "timestamp", "type": "string"},   // <-- changed from long to string (breaking)
        {"name": "metadata", "type": ["null", "string"], "default": null},
        {"name": "balance", "type": {"type": "bytes", "logicalType": "decimal", "precision": 10, "scale": 2}, "default": "0.00"}
      ],
      "doc": "Breaking version (timestamp changed to string)"
    }`;

    // Parse the breaking schema using avsc (required by avro‑registry)
    const breakingSchema = avsc.parse(breakingSchemaStr);

    const success = this.registry.registerWithCompatibility(999, breakingSchema);
    if (!success) {
      console.log('✅ Breaking schema correctly rejected.');
    } else {
      console.error('❌ Breaking schema incorrectly accepted.');
    }
  }

  /**
   * Demonstrates handling of an **unknown schema identifier**.
   */
  public async demonstrateUnknownSchema(): Promise<void> {
    console.log('--- Demonstrating unknown schema identifier ---');

    // Build a fake envelope: magic 0x00, schema ID 3 (not registered), dummy payload
    const dummyPayload = Buffer.from([0x01, 0x02]);
    const envelope = Buffer.alloc(5 + dummyPayload.length);
    envelope[0] = 0x00;
    envelope.writeUInt32BE(3, 1);   // unknown ID
    dummyPayload.copy(envelope, 5);

    try {
      const decoded = this.registry.decode(envelope);
      console.error('❌ Unexpectedly decoded unknown schema:', decoded);
    } catch (e) {
      console.log('✅ Expected error for unknown schema ID:', (e as Error).message);
    }
  }
}
```

## 📄 src/consumer.ts  –  AvroConsumer

```typescript
// src/consumer.ts
import { LocalSchemaRegistry } from './registry';
import { SCHEMA_IDS } from './schemas';

export class AvroConsumer {
  private registry: LocalSchemaRegistry;

  constructor(registry: LocalSchemaRegistry) {
    this.registry = registry;
  }

  /**
   * Decode an envelope, optionally using a different *readerSchemaId*.
   * This demonstrates **schema resolution** (V1 writer → V2 reader).
   */
  public decodeEnvelope(envelope: Buffer, readerSchemaId?: number): any {
    return this.registry.decode(envelope, readerSchemaId);
  }

  /**
   * Demonstrates that a V1 event can be read with a V2 reader schema.
   * The optional `balance` field defaults to `"0.00"` when missing.
   */
  public async demonstrateResolution(): Promise<void> {
    console.log('--- Demonstrating schema resolution ---');

    const registry = new LocalSchemaRegistry();

    // Produce a V1 event (no balance)
    const v1Event = {
      id: 'evt-res-001',
      name: 'Carol',
      status: 'ACTIVE',
      timestamp: Date.now(),
      metadata: 'v1 meta',
    };
    const v1Envelope = registry.encode(SCHEMA_IDS.V1, v1Event);
    console.log('V1 envelope (hex):', v1Envelope.toString('hex'));

    // Decode with V2 reader schema (balance should be defaulted)
    const decoded = registry.decode(v1Envelope, SCHEMA_IDS.V2);
    console.log('Decoded with V2 reader (balance defaulted):', decoded);
  }
}
```

## 📚 API Summary & Compatibility Details

| Component | Function | Avro / Compatibility API | Notes |
|-----------|----------|--------------------------|-------|
| **avsc** | `avsc.parse(schemaJson)` | Core Avro schema parser | Returns `avsc.Schema` used throughout. |
| **avro‑registry** | `register(id, schema)` | Schema storage | Simple in‑memory map. |
| | `get(id)` | Schema retrieval | Used by producer/consumer. |
| | `checkCompatibility(writer, reader, level)` | Compatibility checking | Supports `BACKWARD`, `FORWARD`, `FULL`. |
| **fast‑avro** | `encodeSync(schema, record)` | Binary Avro encoding | Handles logical types (timestamp‑millis, decimal). |
| | `decodeSync(schema, buffer, [readerSchema])` | Binary Avro decoding | Supports reader‑writer schema resolution. |
| **Envelope** | `magic (0x00) + schemaId (uint32 BE) + payload` | Confluent Schema Registry wire format | Producer creates, consumer parses. |
| **LocalSchemaRegistry** | `registerWithCompatibility` | Wrapper around avro‑registry | Enforces backward compatibility before registration. |
| **AvroProducer** | `demonstrateCompatibleEvolution` | Uses registry to register V2 | Shows compatible evolution. |
| | `demonstrateBreakingChange` | Attempts to register a breaking schema | Demonstrates rejection. |
| | `demonstrateUnknownSchema` | Decodes envelope with unknown ID | Shows error handling. |
| **AvroConsumer** | `decodeEnvelope` | Decodes envelope with optional reader schema | Demonstrates schema resolution. |

All **compatibility checks** are performed **locally** – no network call to an external registry is required.
